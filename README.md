# Chess Node Protocol (CNP)

An open protocol between chess programs and the nodes that serve them: chess engines, and
voice modules that speak and listen. JSON-RPC 2.0 over stdin/stdout, and later over WebSocket
with TLS.

Work in progress: the specification, the `cnp` Rust crate and the conformance tests are
coming in the first pull request.
